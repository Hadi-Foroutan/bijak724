# پروفایل من

[← فهرست بخش‌ها](README.md)

**پنل:** پنل شرکت — **تعداد روت:** ۲

مشاهده و ویرایش پروفایل کاربر جاری (فقط خودش). این روت‌ها مجوز دارند (`profile.show`، `profile.update`) ولی مجوزهای پروفایل «فقط ادمین» هستند: در لیست دسترسی‌های کاربران شرکت (`user/{user}/permissions`) نمی‌آیند و مدیر شرکت نمی‌تواند آن‌ها را بردارد یا بدهد؛ فقط در لیست دسترسی‌های پنل ادمین (گروه «مدیریت پروفایل کاربر») دیده و تیک می‌خورند. کاربران جدید به‌صورت پیش‌فرض هر دو را دارند.

### ۴.۱ روت‌ها و مجوزها

| #   | متد  | مسیر                | نوع ورودی           | مجوز لازم                                 | کاربرد                                 |
|-----|------|---------------------|---------------------|-------------------------------------------|----------------------------------------|
| ۴.۱ | GET | `/api/user/profile` | — | `profile.show` | مشاهده پروفایل خودم |
| ۴.۲ | POST | `/api/user/profile` | multipart/form-data | `profile.update` | ویرایش پروفایل خودم (multipart، تصویر) |

### ۴.۳ ورودی و خروجی

ویرایش پروفایل کاربر جاری (هر کاربر فقط خودش). مجوز لازم: `profile.update`. برای آپلود تصویر از `multipart/form-data` استفاده کنید. همهٔ فیلدها اختیاری‌اند و فقط فیلدهای
ارسال‌شده تغییر می‌کنند.

| فیلد                                                     | نوع         | قواعد                                                  |
|----------------------------------------------------------|-------------|--------------------------------------------------------|
| `username`                                               | string      | یکتا در سیستم (نگه‌داشتن نام فعلی مجاز است)؛ حداکثر ۲۵۵ |
| `first_name`، `last_name`                                | string      | حداکثر ۲۵۵                                             |
| `print_name`                                             | string/null | عنوان چاپی                                             |
| `national_code`                                          | string      | یکتا                                                   |
| `personal_code`، `telephone`                               | string/null | حداکثر ۲۰                                              |
| `phone`                                                  | string/null | شماره همراه؛ یکتا                                      |
| `min_commission_percentage`، `max_commission_percentage` | number      | ۰ تا ۱۰۰                                               |
| `address`                                                | string/null |                                                        |
| `password`                                               | string/null | حداقل ۷؛ اگر ارسال نشود یا خالی باشد رمز تغییر نمی‌کند  |
| `profile_image`                                          | file        | jpg، jpeg، png، webp؛ حداکثر ۵۱۲۰ کیلوبایت             |
| `remove_profile_image`                                   | bool        | حذف تصویر فعلی                                         |

پاسخ: `UserResource` به‌روزشده (همان ساختار کاربران شرکت).
