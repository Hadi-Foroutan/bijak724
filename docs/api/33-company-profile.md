# اطلاعات شرکت (پنل شرکت)

[← فهرست بخش‌ها](README.md)

**پنل:** پنل شرکت — **تعداد روت:** ۲

صفحهٔ «اطلاعات شرکت»: کاربر شرکت اطلاعات **شرکت خودش** را می‌بیند و ویرایش می‌کند و لوگو و امضای شرکت را بارگذاری می‌کند.
شرکت از روی توکن مشخص می‌شود؛ شناسهٔ شرکت در آدرس نمی‌آید و ویرایش شرکت دیگر ممکن نیست.

### ۳۳.۱ روت‌ها و مجوزها

| #    | متد                | مسیر                | نوع ورودی                                | مجوز لازم             | کاربرد                                |
|------|--------------------|---------------------|------------------------------------------|-----------------------|---------------------------------------|
| ۳۳.۱ | GET                | `/api/user/company` | ندارد                                    | `user.company.show`   | اطلاعات شرکت                          |
| ۳۳.۲ | POST\|PUT\|PATCH   | `/api/user/company` | `multipart/form-data` (یا JSON بدون تصویر) | `user.company.update` | ویرایش اطلاعات و بارگذاری لوگو و امضا |

- برای بارگذاری تصویر باید `multipart/form-data` بفرستید و چون مرورگر فرم چندبخشی را با `PUT` نمی‌فرستد، از **`POST`** استفاده کنید
  (مثل بقیهٔ فرم‌های بارگذاری). بدون تصویر هر سه متد کار می‌کنند و JSON هم پذیرفته می‌شود.
- مجوز `user.company.update` **پیش‌فرض به همهٔ کاربران داده نمی‌شود** و مدیر باید آن را برای کاربر تیک بزند. مشاهده (`user.company.show`) برای همه است.
  نقش دمو هم نمی‌تواند ویرایش کند.

### ۳۳.۲ خروجی (`GET` و پاسخ ویرایش)

```json
{
  "success": true,
  "message": "عملیات موفق بود",
  "data": {
    "id": 1000,
    "name": "شرکت فنی مهندسی سافر مهر خاوند",
    "organization_code": "2488955",
    "national_code": "11290090811",
    "panel_code": "58231",
    "technical_contact_first_name": "بهار",
    "technical_contact_last_name": "کشوری",
    "technical_contact_phone": "09909967286",
    "city_code": 1101,
    "postal_code": "6673433090",
    "address": "اصفهان، خیابان طالقانی، ...",
    "tel": "37776729",
    "fax": null,
    "website": "safer.ir",
    "contact_code1": null,
    "contact_code2": null,
    "contact_code3": null,
    "description": null,
    "logo_url": "https://api.bijak724.ir/storage/companies/1000/logo/abc.png",

    "status": "active",
    "email": null,

```

`logo_url` و `signature_url` آدرس کامل تصویرند و اگر تصویری بارگذاری نشده باشد `null` هستند. (فیلد قدیمی `logo` مسیر ذخیره‌شده است؛ برای نمایش `logo_url` را بخوانید.)
استان را از روی `city_code` (شهر انتخاب‌شده) از [اطلاعات پایه](09-general-lookups.md) بخوانید.

### ۳۳.۳ ورودی ویرایش

همهٔ کلیدها اختیاری‌اند؛ کلیدی که نفرستید مقدارش عوض نمی‌شود. برای خالی کردن یک فیلد اختیاری `null` (یا رشتهٔ خالی در فرم) بفرستید.

| فیلد در فرم                | کلید ارسال                                                    | قاعده                                                      |
|----------------------------|---------------------------------------------------------------|------------------------------------------------------------|
| نام شرکت                   | `name`                                                        | رشته، حداکثر ۲۵۵، خالی نباشد                               |
| کد سازمانی                 | `organization_code`                                           | رشته، حداکثر ۲۵۵، **یکتا بین همهٔ شرکت‌ها** (مقدار فعلی خود شرکت مجاز است) |
| شناسه ملی                  | `national_code`                                               | رشته، حداکثر ۲۰، **یکتا بین همهٔ شرکت‌ها**                  |
| رابط فنی (نام و نام خانوادگی) | `technical_contact_first_name`، `technical_contact_last_name` | رشتهٔ اختیاری، حداکثر ۲۵۵ (در فرم یک کادر است: فرانت آن را به دو بخش تقسیم کند) |
| همراه رابط فنی             | `technical_contact_phone`                                     | رشتهٔ اختیاری                                              |
| شهر                        | `city_code`                                                   | کد شهر موجود در لیست شهرها؛ خالی نباشد                      |
| کد پستی                    | `postal_code`                                                 | رشتهٔ اختیاری، حداکثر ۲۰                                   |
| آدرس                       | `address`                                                     | متن اختیاری                                                |
| تلفن                       | `tel`                                                         | رشتهٔ اختیاری                                              |
| فکس                        | `fax`                                                         | رشتهٔ اختیاری                                              |
| وب سایت                    | `website`                                                     | رشتهٔ اختیاری (مثلاً `safer.ir`)                            |
| کد واسط ۱ تا ۳             | `contact_code1`، `contact_code2`، `contact_code3`             | رشتهٔ اختیاری                                              |
| توضیحات                    | `description`                                                 | متن اختیاری                                                |
| بارگذاری لوگو              | `logo`                                                        | فایل تصویر `jpg`/`jpeg`/`png`/`webp`، حداکثر ۵ مگابایت     |
| بارگذاری امضا              | `signature`                                                   | فایل تصویر با همان شرایط لوگو                              |
| حذف لوگو                   | `remove_logo`                                                 | بولی؛ `true` لوگوی فعلی را پاک می‌کند                       |
| حذف امضا                   | `remove_signature`                                            | بولی؛ `true` امضای فعلی را پاک می‌کند                       |

- بارگذاری تصویر جدید، تصویر قبلی همان فیلد را جایگزین و فایل قدیمی را پاک می‌کند. اگر هم `logo` و هم `remove_logo` بفرستید، تصویر جدید اعمال می‌شود.
- فایل نامعتبر (غیرتصویر یا بزرگ‌تر از حد) `422` با خطای همان فیلد می‌دهد.
- مثال فرم (multipart): `POST /api/user/company` با `name`، `website` و فایل `logo`.

### ۳۳.۴ چیزهایی که شرکت نمی‌تواند عوض کند

این‌ها را فقط ادمین (`PUT /api/admin/companies/{id}`) تغییر می‌دهد و اگر در درخواست باشند **نادیده گرفته می‌شوند** (خطا نمی‌دهند):
`parent_id`، `parent_type` (سرپرستی و شعبه بودن)، `status`، `panel_code`، `email`، `brand`.

### ۳۳.۵ خطاها

| وضعیت | چه زمانی                                                                                     |
|-------|----------------------------------------------------------------------------------------------|
| `422` | `organization_code` یا `national_code` تکراری، شهر نامعتبر، نام خالی، فایل نامعتبر           |
| `403` | کاربر مجوز `user.company.update` را ندارد                                                    |
| `401` | توکن ارسال نشده یا منقضی است                                                                 |
