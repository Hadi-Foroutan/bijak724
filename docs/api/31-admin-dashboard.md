# داشبورد ادمین

[← فهرست بخش‌ها](README.md)

**پنل:** پنل ادمین — **تعداد روت:** ۴

آمار فقط‌خواندنی کل سیستم (همهٔ شرکت‌ها). هر بخش داشبورد مسیر و متد جداگانهٔ خودش را دارد؛ فرانت‌اند هر کدام را جدا صدا می‌زند
و هر کدام کش جداگانه دارد.

### ۳۱.۱ روت‌ها و مجوزها

| #    | متد | مسیر                              | نوع ورودی | مجوز لازم                      | کاربرد                        |
|------|-----|-----------------------------------|-----------|--------------------------------|-------------------------------|
| ۳۱.۱ | GET | `/api/admin/dashboard`            | ندارد     | `admin.dashboard.index`        | شمارنده‌های خلاصهٔ سیستم       |
| ۳۱.۲ | GET | `/api/admin/dashboard/companies/top/seven` | ندارد  | `admin.dashboard.companies-top-seven` | ۷ شرکت برتر (بیشترین بارنامه) |
| ۳۱.۳ | GET | `/api/admin/dashboard/waybills/monthly` | ندارد | `admin.dashboard.waybills-monthly` | بارنامه‌های صادرشدهٔ ۱۲ ماه اخیر |
| ۳۱.۴ | GET | `/api/admin/dashboard/companies/top/monthly` | ندارد | `admin.dashboard.companies-top-monthly` | ۷ شرکت برتر هر یک از ۱۲ ماه اخیر |

هر دو روت بدنه و query string نمی‌گیرند. توکن پنل ادمین و مجوز بالا لازم است؛ بدون توکن `401` و بدون مجوز `403`
(قالب خطاها: [بخش ۱](01-general-conventions.md)). مجوزها را با `php artisan generate-permissions` بسازید و به نقش ادمین بدهید.

### ۳۱.۲ خلاصه — `GET /api/admin/dashboard`

**ورودی:** ندارد.

**خروجی (`200`):**

```json
{
  "data": {
    "total_waybills": 1250,
    "today_waybills": 38,
    "active_companies_today": 9,
    "total_companies": 54,
    "total_users": 210
  }
}
```

| فیلد                     | نوع | توضیح                                                                                  |
|--------------------------|-----|----------------------------------------------------------------------------------------|
| `total_waybills`         | int | تعداد کل بیجک‌های همهٔ شرکت‌ها                                                          |
| `today_waybills`         | int | بیجک‌هایی که امروز ثبت شده‌اند (بر پایهٔ زمان ثبت)                                       |
| `active_companies_today` | int | شرکت‌هایی که امروز دست‌کم یک بیجک ثبت کرده‌اند (هر شرکت یک بار شمرده می‌شود)             |
| `total_companies`        | int | تعداد شرکت‌ها                                                                          |
| `total_users`            | int | تعداد کاربران شرکت‌ها؛ کاربران پنل ادمین (بدون شرکت) شمرده نمی‌شوند                       |

### ۳۱.۳ ۷ شرکت برتر — `GET /api/admin/dashboard/companies/top/seven`

**ورودی:** ندارد. شرکت‌ها از نظر تعداد کل بارنامه‌های صادرشده مرتب می‌شوند، بدون توجه به زمان صدور.

**خروجی (`200`):**

```json
{
  "data": {
    "items": [
      { "company_id": 3, "name": "شرکت نمونه", "organization_code": "10470", "count": 120 },
      { "company_id": 8, "name": "شرکت دوم", "organization_code": "10512", "count": 97 }
    ]
  }
}
```

| فیلد                        | نوع          | توضیح                                                                              |
|-----------------------------|--------------|------------------------------------------------------------------------------------|
| `items`                     | array        | حداکثر ۷ شرکت، از پرتعداد به کم‌تعداد؛ در تساوی، شرکت با `company_id` کوچک‌تر اول    |
| `items[].company_id`        | int          | شناسهٔ شرکت                                                                        |
| `items[].name`              | string       | نام شرکت                                                                           |
| `items[].organization_code` | string\|null | کد سازمانی                                                                         |
| `items[].count`             | int          | تعداد کل بارنامه‌های **صادرشده** (وضعیت `completed`) در هر زمانی                      |

- بارنامه‌های شعبه‌ها به نام خود شعبه شمرده می‌شوند (نه شرکت مادر).
- بارنامه‌های حذف‌شده و غیر `completed` شمرده نمی‌شوند.
- شرکتی که هیچ بارنامهٔ صادرشده‌ای ندارد در لیست نمی‌آید؛ اگر هیچ شرکتی نداشته باشد، `items` آرایهٔ خالی است.

### ۳۱.۴ بارنامه‌های ماهانه — `GET /api/admin/dashboard/waybills/monthly`

**ورودی:** ندارد. همیشه **۱۲ ماه اخیر** است: ماه جاری و ۱۱ ماه قبل از آن (ماه میلادی، با همان قالب `GET /api/user/dashboard/waybills/monthly` داشبورد شرکت).

**خروجی (`200`):**

```json
{
  "data": {
    "from": "2025-11",
    "to": "2026-10",
    "items": [
      { "month": "2025-11", "label": "نوامبر 2025", "count": 0 },
      { "month": "2025-12", "label": "دسامبر 2025", "count": 14 },
      { "month": "2026-10", "label": "اکتبر 2026", "count": 40 }
    ]
  }
}
```

- `items` همیشه **۱۲ ردیف** دارد، از قدیمی به جدید؛ ماهی که بارنامه نداشته باشد با `count: 0` می‌آید.
- `month`: کلید ماه (`YYYY-MM`)، `label`: عنوان آمادهٔ نمایش، `count`: تعداد بارنامه‌های **صادرشده** (وضعیت `completed`) همهٔ شرکت‌ها که تاریخ صدورشان در آن ماه است.

### ۳۱.۵ شرکت‌های برتر هر ماه — `GET /api/admin/dashboard/companies/top/monthly`

**ورودی:** ندارد؛ همان ۱۲ ماه اخیر.

**خروجی (`200`):**

```json
{
  "data": {
    "from": "2025-11",
    "to": "2026-10",
    "items": [
      { "month": "2025-11", "label": "نوامبر 2025", "companies": [] },
      {
        "month": "2026-10",
        "label": "اکتبر 2026",
        "companies": [
          { "company_id": 1001, "name": "شرکت نمونه", "organization_code": "2101063", "count": 27 },
          { "company_id": 1000, "name": "شرکت دوم", "organization_code": "1020663", "count": 9 }
        ]
      }
    ]
  }
}
```

- `items` همیشه ۱۲ ردیف است، از قدیمی به جدید. هر ماه حداکثر ۷ شرکت در `companies` دارد، از پرتعداد به کم‌تعداد (در تساوی، `company_id` کوچک‌تر اول).
- ماهی که بارنامهٔ صادرشده نداشته باشد `companies: []` دارد.
- `count` تعداد بارنامه‌های **صادرشدهٔ** (`completed`) همان شرکت در همان ماه است؛ بارنامهٔ شعبه به نام خود شعبه شمرده می‌شود.

### ۳۱.۶ کش

هر بخش کلید کش خودش را دارد: خلاصه روزانه (با تاریخ امروز)، شرکت‌های برتر (بدون تاریخ) و دو بخش ماهانه (با ماه جاری). کش داشبورد کاربر و ادمین یک کلید دارند:

| متغیر `.env`                    | پیش‌فرض | کار                                                         |
|---------------------------------|---------|-------------------------------------------------------------|
| `DASHBOARD_CACHE`               | `true`  | `false` یعنی هر بار مستقیم از دیتابیس خوانده می‌شود          |
| `DASHBOARD_CACHE_TTL_SECONDS`   | `7200`  | عمر کش (فقط وقتی کش روشن است)                               |

بعد از تغییر `.env` دستور `php artisan optimize:clear` را بزنید (در دیپلوی خودکار انجام می‌شود). با کش روشن، اعداد تا پایان عمر کش
ممکن است کمی عقب باشند.
